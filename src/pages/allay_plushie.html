About

The allay plushie is a decorative plushie inspired by the allay mob!

Crafting Recipe

Craft the Allay plushie by filling the top and bottom rows with light blue wool and placing an amethyst shard between two white wool in the middle row.

Config

  • In-Game Screen Name: Enable Allay Plushie
  • Config File Key: enable_allay_plushie
  • Default: true / Yes

Determines whether allay plushies are obtainable.

  • true / Yes: Allay plushies are enabled.
  • false / No: Allay plushies are disabled and hidden.
