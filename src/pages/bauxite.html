About

Bauxite is a block of sedimentary rock, found in large pockets underground in the mesa biome.

The bauxite slab is a slab↗ variant of bauxite.

The bauxite stairs block is a stairs↗ variant of bauxite.

Technical

Configuration
  • In-Game Screen Name: Enable Bauxite
  • Config File Key: enable_bauxite
  • Default: true / Yes

Determines whether Bauxite, bauxite stairs, bauxite slabs, and bauxite walls can be obtained.

  • true / Yes: They are enabled.
  • false / No: They are disabled and hidden.
