About

The bog blossom is a decorative block that emits yellow particles!

Natural generation

Bog blossoms can be found in both vanilla swamps and modded swamps on land. Without other mods installed this is limited to swamps and mangrove swamps.

Obtaining

Bog blossoms can be obtained from swamps or by using bonemeal on a bog blossom. When a bog blossom is bonemealed another will grow nearby!

Breaking

Bog blossoms can be broken with any item or by hand.

Placing

Bog blossoms can be placed on any supporting solid block.

Config

enable_bog_blossoms (or Enable Bog Blossoms): Determines whether bog blossoms spawn naturally in the world and are obtainable. Default value is true (Yes).

  • true / Yes: Bog blossoms are enabled.
  • false / No: Bog blossoms are disabled and hidden.
