About

The cow plushie is a decorative block inspired by the cow mob!

Config

Set Enable Cow Plushies to Yes/true (default) to use them, or No/false to hide them. All cow plushies use this option.

Placement

When placing a cow plushie, it will face the player.

Breaking

Cow Plushies can be broken with any item or by hand!
