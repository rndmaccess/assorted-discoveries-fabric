About

The dirt path slab is a decorative block that is the path form of the dirt slab and grass slab blocks.

Config

Dirt path slabs are enabled and disabled with the same config setting as dirt slabs. Visit the dirt slabs page to read more about it.

Making Path Slabs

Dirt path slabs can be made by using a shovel on any dirt, coarse dirt, rooted dirt, grass, podzol, or mycelium slabs.

Breaking

Breaking a single upper or lower dirt path slab drops one dirt slab. If however, a double dirt path slab is made it acts as a whole block and when broken they will drop two dirt slabs instead of one.
