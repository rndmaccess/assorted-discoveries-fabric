About

The dirt path slab is a decorative slab that is the path form of the dirt slab and grass slab blocks.

Config

Dirt path slabs are enabled/disabled indirectly with the dirt slab config setting.

  • In-Game Screen Name: Enable Dirt Slabs
  • Config File Key: enable_dirt_slabs

Visit the dirt slabs page for more information.

Usage

Like vanilla dirt paths. Dirt path slabs are 15/16 of a block, therefore items that require a full block like torches and buttons cannot be placed on them. Like normal paths, placing a block that covers the path slab will convert it to a dirt slab.

Making Path Slabs

Dirt path slabs can be made by using a shovel, on any dirt, coarse dirt, rooted dirt, grass, podzol, or mycelium slabs. If there is a block covering the slab it cannot be converted to a dirt path slab.

Breaking

Breaking a single upper or lower dirt path slab drops one dirt slab. If however, a double dirt path slab is made it acts as a whole block and when broken they will drop two dirt slabs instead of one.
