About

The dirt slab is a decorative block that can be combined into a single block.

Config

Set the Enable Dirt Slabs option to Yes (or true) to use them, or No (or false) to hide them. All dirt slabs use this option. Yes (or true) is the default setting.

Slabbed Support

If the slabbed mod is installed it will allow you to place tall grass and many other plants on these slabs. If however, it's not present the bottom slab variant will not support plants.

Growing Grass (Normal dirt slabs only)

If bonemeal is used on a dirt slab it will transform into a grass slab. The slab type (top, bottom, double) will remain the same.

Double Slabs

Only two dirt slabs of the same type can form a double slab unless a different mod changes this behavior.

Breaking

Breaking a single upper or lower dirt slab drops one slab. If however, two dirt slabs are put together they act as a whole block and when broken they will drop two slabs instead of one.
