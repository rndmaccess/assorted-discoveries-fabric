About

The dyed torch is a variant of the torch that comes in all 16 dye colors.

Config

  • In-Game Screen Name: Enable Dyed Torches
  • Config File Key: enable_dyed_torches
  • Default: true / Yes

Determines whether dyed torches can be obtained.

  • true / Yes: Dyed torches are enabled.
  • false / No: Dyed torches are disabled and hidden.

Breaking

Dyed torches can be broken instantly using anything, and drop themselves as an item. These torches break in the same exact conditions as normal torches.

Placing

Dyed torches act exactly like a normal torch when placed.

Crafting Recipe

Craft a dyed torch by placing a torch and any color of dye in any arrangement.
