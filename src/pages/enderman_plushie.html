About

The enderman plushie is a decorative block inspired by the enderman mob!

Config

Set Enable Enderman Plushie to Yes/true (default) to activate this block, or No/false to disable it.

Grass Block Color

The plushie’s grass block changes color to match its current biome.

Placement

When placing an enderman plushie, it will face the player.

Breaking

Enderman Plushies can be broken with any item or by hand!

Crafting Recipe

Craft the enderman plushie by filling the top row with black wool, placing an ender pearl between two magenta wool in the middle row, and placing a grass block between two black wool in the bottom row.
