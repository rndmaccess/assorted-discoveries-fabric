About

The enderman plushie is a decorative plushie inspired by the enderman mob!

Config

  • In-Game Screen Name: Enable Enderman Plushie
  • Config File Key: enable_enderman_plushie
  • Default: true / Yes

Determines whether enderman plushies can be obtained.

  • true / Yes: Enderman plushies are enabled.
  • false / No: Enderman plushies are disabled and hidden.

Grass Block Color

The plushie’s grass block changes color to match its current biome.

Crafting Recipe

Craft the enderman plushie by filling the top row with black wool, placing an ender pearl between two magenta wool in the middle row, and placing a grass block between two black wool in the bottom row.
