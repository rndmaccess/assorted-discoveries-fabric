About

Forest's Bounty is an early game food item that can be crafted from sweet berries and spruce cones.

Config

enable_forests_bounty (or Enable Forest's Bounty): Determines whether forest's bounty is obtainable. Default value is true (Yes).

  • true / Yes: Forest's bounty items are enabled.
  • false / No: Forest's bounty items are disabled and hidden.

Crafting Recipes

Craft forest's bounty by placing a bowl, sweet berries, and a spruce cone in any arrangement.
