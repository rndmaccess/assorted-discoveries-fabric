About

The grass slab is a decorative block that can be combined into a single block. These slabs come in three different variants grass, podzol, and mycelium.

Config

Grass slabs are enabled and disabled with the same config option as dirt slabs. Visit the dirt slabs page to read more about it.

Making Path Slabs

Any variant of grass slab can be made into a dirt path slab by using a shovel on it.

Bonemeal

Unlike grass blocks, grass slabs do not spread instead bonemeal turns dirt slabs into grass slabs. If bonemeal is used on an upper or double normal grass slab it will grow flowers and tall grass. Additionally, if the Slabbed mod is installed lower grass slabs can grow flowers and tall grass as well.

Placing Plants

Only the top and double variants support plants normally. However, if the Slabbed mod is installed the bottom variant will support plants as well.

Breaking

Breaking a single upper or lower grass slab drops one slab. If however, two grass slabs are put together they act as a whole block and when broken they will drop two slabs instead of one. Unlike grass blocks, grass slabs always drop themselves instead of dirt slabs.

Double Slabs

Only two grass slabs of the same type can form a double slab unless a different mod changes this behavior.

Crafting Recipe

6

Craft 6 grass slabs using 3 of any grass block (normal, podzol, mycelium) in the top, middle, or bottom row.
