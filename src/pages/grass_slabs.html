About

The grass slab, podzol slab, and mycelium slab are decorative slab variants of the grass, podzol , and mycelium blocks.

Config

Grass slabs are enabled/disabled indirectly with the dirt slab config setting.

  • In-Game Screen Name: Enable Dirt Slabs
  • Config File Key: enable_dirt_slabs

Visit the dirt slabs page for more information.

Making Path Slabs

Using a shovel on a grass, podzol, or mycelium slab transforms it into a dirt path slab.

Bonemeal

Unlike grass blocks, grass slabs do not spread. Instead, bone meal turns dirt slabs into the various grass slab variants. Like normal dirt, coarse dirt slabs and rooted dirt slabs cannot grow grass.

Grass

By default, when bone meal is applied to dirt slabs directly, they will become grass slabs.

If bone meal is used on an upper or double normal grass slab, it will grow flowers and tall grass. Additionally, if the Slabbed mod is installed lower grass slabs can grow flowers and tall grass as well.

Mycelium

If a mycelium slab or mycelium block is touching the dirt slab, it will instead become a mycelium slab.

Podzol

If a podzol slab or podzol block is touching the dirt slab, it will instead become a podzol slab.

Placing Plants

By default, the top and double variants are the only variants that support plants. However, if the Slabbed mod is installed, the bottom variant supports plants as well.

Grass

Grass slabs support any plants that can be planted on grass blocks.

Mycelium

Mycelium slabs support any plants that can be planted on mycelium blocks.

Podzol

Podzol slabs support any plants that can be planted on podzol blocks.

Breaking

Breaking a single slab drops one slab, while a double slab drops two. Unlike their full-block counterparts, grass, podzol, and mycelium slabs always drop their respective slab type instead of reverting to dirt slabs.

Double Slabs

Only two grass slabs of the same type can form a double slab unless a different mod changes this behavior, similarly to normal slabs.

Particles (Only Mycelium)

The mycelium slab gives off particles that resembles tiny spores being released constantly from the surface.

Crafting Recipe

6

Craft six grass slabs by placing three of any grass block in a single row.
