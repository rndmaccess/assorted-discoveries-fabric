About

Green onions are a food item that can be eaten as is or used in crafting recipes.

Config

Green onion items are enabled/disabled indirectly with the green onions config setting.

  • In-Game Screen Name: Enable Green Onions
  • Config File Key: enable_green_onions

Visit the Green onion seeds page for more information.

Obtaining

Green onions can be obtained from harvesting green onion crops. These can be planted from green onion seeds.

Crafting Recipe

Craft noodle soup by placing a bowl, noodles, and a green onion in any arrangement.

Note: If green onions are disabled, the crafting recipe excludes them.
