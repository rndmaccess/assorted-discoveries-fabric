About

Cindersnap berry juice is a nether food item that is made from cindersnap berries.

Frostbite berry juice is a nether food item that is made from frostbite berries.

Config

Cindersnap berry juice

  • In-Game Screen Name: Enable Cindersnap Berry Juice
  • Config File Key: enable_cindersnap_berry_juice
  • Default: true / Yes

Determines whether cindersnap berry juice is available to be crafted and used.

  • true / Yes: Cindersnap berry juice is enabled.
  • false / No: Cindersnap berry juice is disabled.

Dependency: If cindersnap berries are disabled, cindersnap berry juice will be automatically disabled as well. Visit the nether berries page to read more about these berries.

Frostbite berry juice

  • In-Game Screen Name: Enable Frostbite Berry Juice
  • Config File Key: enable_frostbite_berry_juice
  • Default: true / Yes

Determines whether frostbite berry juice is available to be crafted and used.

  • true / Yes: Frostbite berry juice is enabled.
  • false / No: Frostbite berry juice is disabled.

Dependency: If frostbite berries are disabled, frostbite berry juice will be automatically disabled as well. Visit the nether berries page to read more about these berries.
