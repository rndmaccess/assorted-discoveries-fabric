About

Crimson forage mix is a nether food item that is made from combining cindersnap berries and crimson forest plants.

Warped forage mix is a nether food item that is made from combining frostbite berries and warped forest plants.

When consumed, both forage mixes restore the highest amount of hunger and saturation of any stackable food item, surpassing the golden carrot.

Config

Crimson Forage Mix

  • In-Game Screen Name: Enable Crimson Forage Mix
  • Config File Key: enable_crimson_forage_mix
  • Default: true / Yes

Determines whether crimson forage mix is available to be crafted and used.

  • true / Yes: Crimson forage mix is enabled.
  • false / No: Crimson forage mix is disabled.

Dependency: If cindersnap berries are disabled, crimson forage mix will be automatically disabled as well. Visit the nether berries page to read more about these berries.

Warped Forage Mix

  • In-Game Screen Name: Enable Warped Forage Mix
  • Config File Key: enable_warped_forage_mix
  • Default: true / Yes

Determines whether warped forage mix is available to be crafted and used.

  • true / Yes: Warped forage mix is enabled.
  • false / No: Warped forage mix is disabled.

Dependency: If frostbite berries are disabled, warped forage mix will be automatically disabled as well. Visit the nether berries page to read more about these berries.

Crafting Recipes

Crimson Forage Mix

Craft crimson forage mix by placing three cindersnap berries and three of any crimson vegetation in any arrangement.

Warped Forage Mix

Craft warped forage mix by placing three frostbite berries and three of any warped vegetation in any arrangement.
