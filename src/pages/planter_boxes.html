About

The planter box is a decorative block that can be dynamically expanded by placing more planter boxes next to each other.

Expansion

Planter boxes of different types won't connect. Planter boxes need to share the same wood type to expand.

Sapling Behavior

When a sapling grows into a tree the planter box underneath will not be converted to dirt.

Farming

Planter boxes that are made from overworld wood allow overworld plants to thrive in them! Nether wood planter boxes, on the other hand, only support nether plants. These plants will grow in the planter box the same way that they would if they were planted on wet farmland↗ or soul soil↗.

The following plants can be grown in overworld planter boxes:

  • wheat↗
  • carrots↗
  • potatoes↗
  • beetroots↗
  • sweet berries↗
  • flowers↗
  • sugar cane↗
  • saplings↗
  • wild green onions
  • green onions

The following plants can be grown in nether planter boxes:

  • nether wart↗
  • crimson roots↗
  • warped roots↗
  • crimson fungi↗
  • warped fungi↗
  • nether sprouts↗

Any plants added to the tags listed in the tags section are also supported.

Technical

Configuration
  • In-Game Screen Name: Enable Planter Boxes
  • Config File Key: enable_planter_boxes
  • Default: true / Yes

Determines whether all planter boxes are obtainable, nether and overworld.

  • true / Yes: Planter boxes are enabled.
  • false / No: Planter boxes are disabled and hidden.
Tags

Planter boxes support any plant that can grow on the soil types defined by the block tags below. If another mod adds its plants to any of these tags, they will automatically be compatible with planter boxes.

Overworld Planter Boxes

  • minecraft:dirt
  • minecraft:supports_crops
  • c:dirt (Common tag used by modded soils)

Nether Planter Boxes

  • minecraft:supports_warped_roots
  • minecraft:supports_warped_fungus
  • minecraft:supports_nether_wart
  • minecraft:supports_nether_sprouts
  • minecraft:supports_crimson_roots
  • minecraft:supports_crimson_fungus
  • c:soul_ground (Common tag used for Soul Sand and Soul Soil plants)
