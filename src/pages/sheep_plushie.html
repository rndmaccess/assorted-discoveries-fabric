About

The sheep plushie is a decorative block inspired by the various sheep mob variants!

Config

Set Enable Sheep Plushies to Yes/true (default) to use them, or No/false to hide them. All sheep plushies use this option.

Placement

When placing any sheep plushie, it will face the player.

Breaking

Sheep Plushies can be broken with any item or by hand!

Crafting Recipe

Craft any sheep plushie by placing a mutton between 2 black wool in the middle row and 3 of any wool in the top and bottom rows.
