About

A stripped wooden wall is a variant of the wooden wall. Once stripped, it cannot be reversed.

Config

  • In-Game Screen Name: Enable Stripped Wooden Walls
  • Config File Key: enable_stripped_wooden_walls
  • Default: true / Yes

Determines whether stripped wooden walls can be obtained.

Note: If wooden walls are disabled, stripped wooden walls can still be obtained through crafting.

  • true / Yes: Stripped wooden walls are enabled.
  • false / No: Stripped wooden walls are disabled and hidden.
