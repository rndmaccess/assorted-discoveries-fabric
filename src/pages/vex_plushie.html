About

The vex plushie is a decorative block inspired by the vex mob!

Config

Set Enable Vex Plushie to Yes/true (default) to use them, or No/false to hide them.

Placement

When placing a vex plushie, it will face the player.

Breaking

Vex Plushies can be broken with any item or by hand!
