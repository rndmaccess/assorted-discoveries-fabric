About

Witch's cradle soup is a swamp food item that can be crafted from witch's cradle branches.

Config

Witch's cradle soup is enabled/disabled indirectly with the witch's cradle config setting.

  • In-Game Screen Name: Enable Witch's Cradles
  • Config File Key: enable_witchs_cradles

Visit the witch's cradle branch page for more information.

Crafting Recipes

Craft witch's cradle soup by placing six witch's cradle branches and a bowl in any arrangement.
