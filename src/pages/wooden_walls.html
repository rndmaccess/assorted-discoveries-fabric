About

Wooden walls are decorative blocks. These blocks come in 12 variants, one for each type of unmodded wood.

Config

  • In-Game Screen Name: Enable Wooden Walls
  • Config File Key: enable_wooden_walls
  • Default: true / Yes

Determines whether wooden walls can be obtained.

  • true / Yes: Wooden walls are enabled.
  • false / No: Wooden walls are disabled and hidden.

Stripping

Any wooden wall can be stripped by using an axe on it. Stripped wooden walls can also be obtained directly through crafting.
