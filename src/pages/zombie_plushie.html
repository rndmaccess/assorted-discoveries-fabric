About

The zombie plushie is a decorative block inspired by the zombie mob!

Config

Set the Enable Zombie Plushie option to Yes (or true) to use them, or No (or false) to hide them. Yes (or true) is the default setting.

Crafting Recipe

Placement

When placing a zombie plushie, it will face the player.

Breaking

Zombie Plushies can be broken with any item or by hand!
