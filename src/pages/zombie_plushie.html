About

The zombie plushie is a decorative plushie inspired by the zombie mob!

Config

  • In-Game Screen Name: Enable Zombie Plushie
  • Config File Key: enable_zombie_plushie
  • Default: true / Yes

Determines whether zombie plushies can be obtained.

  • true / Yes: Zombie plushies are enabled.
  • false / No: Zombie plushies are disabled and hidden.

Crafting Recipe

Craft the zombie plushie by filling the top and bottom rows with green wool, and placing rotten flesh between two black wool in the middle row.
